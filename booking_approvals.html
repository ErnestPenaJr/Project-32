ABOUT THIS PAGE

This page lists every room reservation waiting on a decision, and lets you approve or reject each one.

Reviewing a Request
  • The table shows the booking ID, who reserved the room, the meeting title, the room and its location, and the start and end dates.
  • Open a request to see its full details, including the room photo, the booked date and time, and the current status.
Approving a Request
  • Click the approve action on the request you want to confirm.
  • Confirm at the "Approve Booking Request?" prompt.
  • The table and the pending count in the navigation bar both refresh once the approval is saved.
Approving Several at Once
  • Tick the checkbox beside each request you want to approve. Only requests that are still pending can be selected — anything already decided shows a dash instead of a checkbox.
  • Use the checkbox in the table header to select every pending request in the current filtered view. If you have searched or filtered first, select-all applies only to the requests that match — not the whole queue.
  • The toolbar above the table shows how many are selected. Your selection is kept as you move between pages.
  • Click Bulk Approve and confirm. Each request is re-checked individually before it is approved, using the same rules as approving one at a time.
  • You will see exactly what happened: how many were approved, and a list of any that could not be, each with the reason — for example a scheduling conflict, or a request someone else already decided while you were working.
  • A request that fails does not stop the rest of the batch. Nothing is changed for the ones that failed, so you can fix the cause and try those again.
  • Clear selection empties your selection without approving anything.
Rejecting a Request
  • Click the reject action on the request you want to decline.
  • Enter a reason for the rejection when prompted — it is recorded with the decision.
  • The table and the pending count refresh once the rejection is saved.
Searching and Sorting
  • Use the search box to filter the requests by any column.
  • Click a column heading to sort by it; click again to reverse the order.
Expired Requests
  • Requests whose end date has already passed are hidden from this list.
  • The list re-checks for newly expired requests about once a minute, so it can change while you are on the page.
